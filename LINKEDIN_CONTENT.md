# LinkedIn project description

DeliverIQ — Delivery, Returns & Logistics Profitability Intelligence

Built an Excel-supported, Power BI-style HTML dashboard to explore a practical supply chain question: which deliveries create value, and which failures erode contribution?

The project analyses 20,000 synthetic footwear orders across eight FYTD monthly cohorts, 10 Indian states, six product categories and four fictional couriers.

Eight interactive pages cover:
• Executive delivery and contribution KPIs
• Courier performance and cost per order
• City/PIN-code delivery risks
• COD versus prepaid outcomes and reattempt recovery
• RTO versus post-delivery customer returns
• Logistics cost and contribution reconciliation
• An adjustable RTO savings simulator
• Searchable order-level data and metric definitions

Each page includes filter-responsive observations, business implications and recommended actions. The supporting Excel workbook contains auditable formulas, monthly summaries, an input-driven scenario and a field dictionary.

Built with Excel, HTML, CSS and JavaScript. The dashboard runs offline without SQL, a database or a Power BI licence.

This is a synthetic portfolio case study. Courier names, operational results and scenario savings are fictional; no realised business savings are claimed.

How much margin disappears after an order leaves the warehouse?

My new project, DeliverIQ, connects delivery performance with returns and logistics profitability using 20,000 synthetic footwear orders.

The Excel-supported HTML dashboard includes eight interactive pages, dynamic insights, courier comparisons, COD analysis, reverse logistics and a savings simulator.

A key modelling choice: I separated RTO from customer returns and used the correct denominator for each. I also distinguished recoverable returned inventory from inventory write-offs, so contribution is not overstated or double-counted.
