# GitHub and portfolio publishing

Suggested repository name: **deliveriq-supply-chain-intelligence**

Suggested repository description: Excel-supported supply chain analytics dashboard for delivery performance, COD, returns and logistics contribution. Offline HTML, 20,000 synthetic orders and eight interactive pages.

## Upload

1. Create a repository in your GitHub account.
2. Upload the **contents** of the extracted DeliverIQ folder, with index.html at the repository root. Do not upload only the ZIP.
3. Keep app.js, style.css, data, docs, screenshots, source and README.md in their relative paths.
4. Use GitHub Pages with a branch-based deployment from the main branch and root folder, where your account supports it.
5. Open the published link, test a filter and the simulator, and copy the actual resulting URL into your portfolio project card and LinkedIn Featured item.

This package is ready to upload; no repository or LinkedIn post has been published on your behalf.
